BAGIAN 1: PEMBUKAAN (ELEVATOR PITCH - 1 MENIT)
================================================================================
[Ucapkan dengan tenang dan percaya diri]:

"Selamat pagi/siang Bapak/Ibu penguji dan rekan-rekan sekalian.
Pada kesempatan kali ini, saya ingin mempresentasikan proyek yang telah saya
kembangkan, yaitu Sistem Absensi Kiosk Karyawan Berbasis WebRTC dan Smart Card
RFID dengan nama repositori 'absen_ntp'.

Sistem ini dirancang khusus untuk terminal absensi mandiri (kiosk) perkantoran
yang cepat, stabil, dan berkinerja tinggi. Tiga keunggulan utama sistem ini:
1. Zero External Framework: Backend dibangun murni menggunakan pustaka standar
   Python (http.server), dan frontend menggunakan Vanilla HTML5, CSS3, dan
   Modern JavaScript tanpa ketergantungan library pihak ketiga.
2. Integrasi Perangkat Keras Plug-and-Play: Mendukung USB RFID Smart Card Reader
   secara langsung dengan emulasi keyboard standar tanpa perlu instal driver.
3. Dual-Layer Storage Resilient: Terintegrasi dengan basis data MariaDB melalui
   parameterized SQL murni, dan dilengkapi fitur Auto-Fallback ke JSON lokal
   sehingga mesin absensi tidak akan pernah macet meskipun server database down."

  (Atau jika ada kartu fisik, cukup tempelkan kartu ke USB RFID Reader).

Penjelasan Anda saat proses berjalan:
"Sekarang kita simulasikan seorang karyawan bernama Budi Santoso melakukan absensi
dengan menempelkan kartu RFID-nya yang bernomor seri UID: 983746128.

Mari kita perhatikan alur otomatis yang terjadi di layar:
1. Begitu kartu di-tap, sistem secara instan mencari ke backend dan memunculkan
   status: 'KARTU TERDETEKSI: BUDI SANTOSO'.
2. Nomor seri kartu '983746128' langsung muncul di kolom RFID Card UID.
3. Kamera langsung mengaktifkan panduan wajah oval (Biometric Face Oval Guide)
   agar posisi wajah karyawan pas dan simetris di tengah.
4. Hitung mundur otomatis 3 - 2 - 1 berjalan di layar.
5. Efek shutter flash putih menyala, mengambil jepretan foto dari canvas video.
6. Foto dikirim ke backend dan langsung muncul status hijau: 'ABSENSI BERHASIL'.
7. Dalam 3 detik, sistem otomatis melakukan pembersihan (reset) kembali ke mode
   standby, siap untuk karyawan berikutnya tanpa perlu sentuh tombol apa pun."

(Tips Tambahan: Anda bisa mencoba kartu kedua dengan UID: 827364928 untuk

LANGKAH 3: MEMBUKTIKAN DATA TERCATAT DI DATABASE MARIADB
--------------------------------------------------------------------------------
Aksi:
1. Buka Terminal / PowerShell di laptop Anda.
2. Jalankan perintah:
   python view_db.py

Penjelasan Anda ke Penguji:
"Sekarang kita buka terminal untuk melihat apakah data absensi tadi benar-benar
masuk ke database MariaDB. Kita jalankan skrip viewer internal 'python view_db.py'.

Bisa kita lihat pada tabel terminal:
1. Pada TABEL EMPLOYEES: Terdaftar master data karyawan beserta relasi RFID UID.
2. Pada TABEL ATTENDANCE: Muncul baris absensi baru dengan ID Karyawan, tanggal,
   jam absensi yang presisi, status 'SUCCESS', dan kolom 'PATH FOTO DI DISK'.

Sesuai standar industri, kami tidak menyimpan file gambar mentah (binary BLOB)
ke dalam MariaDB karena akan membuat ukuran database cepat bengkak hingga puluhan
Gigabyte. Yang kami simpan di MariaDB adalah path lokasinya, sedangkan file fisik
gambar disimpan di partisi penyimpanan harddisk."

LANGKAH 4: MEMBUKTIKAN FOTO TERSIMPAN DI SERVER LINUX VIA SSH
--------------------------------------------------------------------------------
Aksi:
1. Di terminal, masuk ke server Linux Mint via SSH:

2. Masuk ke direktori penyimpanan foto:
   cd employee-attendance/captures/2026/09/05
3. Ketik perintah:
   ls -lh

Penjelasan Anda ke Penguji:
"Sekarang kita remote server Linux Mint kita menggunakan SSH untuk membuktikan
bahwa foto webcam tadi benar-benar terkirim dan tersimpan di server Linux.

Dengan perintah 'ls -lh', kita bisa melihat:
1. Direktori dipartisi secara rapi menurut Tahun/Bulan/Tanggal (2026/09/05).
2. Setiap file foto memiliki format nama unik:
   [ID_KARYAWAN]_[TANGGAL]_[JAM_MENIT_DETIK].png
   Contohnya file 'EMP001_20260905_234337.png' berukuran 1.4 Megabyte.
3. Jika kita verifikasi keaslian filenya menggunakan perintah:
   file EMP001_20260905_234337.png
   Sistem Linux langsung memverifikasi signature magic bytes:
   'PNG image data, 640 x 480, 8-bit/color RGBA'.
   Ini membuktikan secara forensik bahwa file tersebut adalah gambar PNG asli
   hasil jepretan kamera kiosk, bukan sekadar file teks kosong."

BAGIAN 3: CONTEKAN MENJAWAB PERTANYAAN SULIT DARI PENGUJI (FAQ)
================================================================================

TANYA 1:
"Kenapa tidak pakai framework populer seperti Flask, Django, atau React?"
JAWAB:
"Untuk kebutuhan mesin Kiosk mandiri (Embedded / Dedicated Kiosk), performa,
kecepatan startup saat booting, dan minimnya dependensi adalah prioritas utama.
Framework seperti Django atau React menambah ratusan megabyte dependensi (node_modules)
dan memperlambat waktu booting. Dengan Pure Python http.server dan Vanilla JS,
sistem dapat menyala dalam hitungan milidetik, konsumsi RAM di bawah 50 MB,
dan tidak memerlukan maintenance library eksternal yang rumit."

---

TANYA 2:
"Bagaimana jika di lapangan server database MariaDB mendadak down atau mati?"
JAWAB:
"Sistem ini memiliki arsitektur 'Fault-Tolerant Dual Storage'. Lapisan database di
'db.py' dirancang memiliki mekanisme Auto-Fallback. Jika koneksi ke MariaDB gagal,
sistem tidak akan crash atau error 500, melainkan otomatis beralih menyimpan
catatan ke 'data/attendance.json'. Karyawan tetap bisa absen dengan lancar.
Ketika MariaDB sudah online kembali, data dapat disinkronkan ke MariaDB menggunakan
skrip migrasi 'migrate_json_to_db.py'."

---

TANYA 3:
"Bagaimana alat RFID bisa langsung dibaca oleh web browser tanpa software perantara?"
JAWAB:
"Kami menggunakan standar USB HID (Human Interface Device) Keyboard Emulation.
Alat USB RFID Reader dikenali oleh OS seperti keyboard fisik. Saat kartu di-tap,
reader mengetikkan nomor UID kartu dan diakhiri dengan sinyal 'Enter'.
Di sisi browser, kami memasang listener keyboard pada input tersembunyi dengan
fitur auto-focus recovery, sehingga input kartu selalu tertangkap secara instan."

---

TANYA 4:
"Bagaimana sistem ini berjalan otomatis saat komputer Kiosk Linux dinyalakan (booting)?"
JAWAB:
"Kami telah menyiapkan skrip otomasi di folder 'scripts/':
1. Backend dijalankan sebagai Systemd Service ('attendance-server.service') dengan
   fitur 'Restart=always' jika terjadi kendala.
2. Tampilan Kiosk dijalankan melalui XDG Desktop Autostart ('attendance-kiosk.desktop')
   yang meluncurkan browser Chromium dalam mode fullscreen kiosk murni
   tanpa address bar dan tanpa popup izin kamera."

---

TANYA 5:
"Apa rencana pengembangan selanjutnya?"
JAWAB:
"Pada Task 20 berikutnya, kami akan mengintegrasikan teknologi Kecerdasan Buatan (AI)
berupa Face Recognition (Pengenalan Wajah) dan Liveness Detection (Anti-Spoofing)
sehingga verifikasi absensi tidak hanya mengandalkan kartu RFID, tetapi juga
mencocokkan biometrik wajah karyawan secara otomatis."
